# Apex Planet - Task 1: Exploratory Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) using the Sample Superstore dataset.

## Objectives
- Set up the Python data analysis environment
- Load and understand the dataset
- Clean the data
- Handle missing values and duplicates
- Detect outliers
- Perform exploratory data analysis
- Create visualizations to understand the data

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Dataset used: Sample Superstore

## Data Cleaning
The dataset was cleaned by:
- Checking missing values
- Removing duplicate records
- Checking and correcting data types
- Detecting outliers using the IQR method
- Saving the cleaned dataset as `Superstore_Cleaned.csv`

## Exploratory Data Analysis
The analysis includes:
- Statistical summary
- Histograms
- Box plots
- Bar charts
- Correlation analysis
- Heatmap visualization

## Project Files
- `data/` - Dataset and cleaned dataset
- `notebooks/` - Jupyter Notebook containing the analysis
- `reports/` - Reports
- `scripts/` - Python scripts
- `dashboards/` - Dashboard files

## Conclusion
The project demonstrates the process of cleaning, analyzing, and visualizing the Sample Superstore dataset using Python.
